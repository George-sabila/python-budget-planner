# python-budget-planner

Simple CLI student budget planner built with Python, designed for tracking budgets and planned expenses in UGX.

## Features
- Set or update an available budget with automatic overspending warnings
- Add, edit, and remove planned expenses with input validation
- View all expenses in a formatted table
- Check budget summary (remaining balance or deficit)
- View category totals and top 3 largest expenses

## How to Run
Make sure you have Python 3 installed, then run:

```bash
python budget_planner.py
